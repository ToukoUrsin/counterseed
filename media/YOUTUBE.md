## Title

Counterseed — Find the beautiful exception | GIBC V2

## Description

A thousand examples can suggest a rule. One counterexample can change it.

Counterseed is an interactive graph-theory conjecture lab. Build a logical implication, search every small graph, inspect the smallest failure, change an edge, and replay the evidence with a separate verifier.

Try it: https://toukoursin.github.io/counterseed/
Source and verification: https://github.com/ToukoUrsin/counterseed

The demonstration uses the working application: a five-cycle breaks a plausible claim, removing an edge changes the actual computed properties, two triangles expose a fragile bridge, and a complete census checks 33,867 labeled graphs through six vertices. Passing a finite census is bounded evidence, never an unbounded theorem proof.
